# 群问答已确认事实

记录日期：2026-11-16

来源：用户提供的赛题群问答记录。原始文本保存在 `group_qa_raw.txt`。

## 已确认

1. 官方评测平台：<https://rsi-index.115.zone>
2. 平台要求选手注册；完整的队伍和队员信息需要审批。
3. 平台已经发布比赛数据集。
4. 平台已经提供初始 baseline，参赛者可以在 baseline 基础上优化。
5. 平台会提供标签，选手不需要自行构造官方标签。
6. 评分由平台定制的 Agent 执行，最终应以平台评分和提交校验为准。
7. 协会赛阶段暂不统一提供服务器等算力，算力在进入企业赛阶段后提供。
8. 选手应自行编写提交和评估相关代码，具体标准以官方规则为准。

## 对当前项目的直接影响

- 本地下载的 UCI、XJTU-SY 和 CMAPSS 数据只能用于预研和适配测试。
- 正式训练、验证、特征处理和指标计算必须优先使用平台发布的训练包、标签、切分和
  baseline。
- 不能把本地自己的切分结果写成官方成绩，也不能用公开数据结果代替平台 B 包结果。
- 应先复现平台 baseline，再设计漂移迭代和回滚。
- Agent 的训练循环必须适配平台定制评分 Agent 的输入输出，而不是假定本地脚本的接口
  就是最终接口。

## 仍待确认

1. 客观分最终采用“漂移综合性能 + 最差阶段 + 恢复速度 + 稳定性 + 资源效率”的明细
   口径，还是规则 PDF 中偏向单位增益资源消耗的口径。
2. “标注配额”这一项是否仍计入评分。
3. B 包是否仍为气体、轴承、发动机三类任务，或会出现其他任务。
4. 每批输出模型或不上线判断的固定提交格式。
5. B 包每批是重发全部历史数据，还是只发增量数据。
6. 初始提示词由平台统一提供，还是由参赛者随镜像提交。
7. 平台对持久化 Sampler 微调权重的校验要求。群内已有案例显示基础模型校验通过，而
   LoRA Sampler 权重路径校验失败，版主回复“权重没有完成保存”。
8. Swan Lab 在离线评测环境中的记录、同步和公开方式。
